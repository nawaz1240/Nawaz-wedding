## Wedding Invitation

A premium, cinematic digital wedding invitation featuring elegant Islamic design, royal palace doors, golden animations, and a memorable interactive opening experience.

## Overview

This project is a personalized digital wedding invitation for **Madeeha Vikhath** and **Mohammed Ameenuddin Ashrafi**. It combines traditional Muslim wedding aesthetics with modern web animations to create an elegant, immersive experience for guests.

## Features

- **Cinematic Hero Section** — Royal palace doors with an interactive opening animation.
- **Islamic-Inspired Design** — Elegant geometric patterns, ornamental arches, and refined typography.
- **Golden Visual Effects** — Atmospheric lighting, floating particles, and smooth transitions.
- **Interactive Invitation** — Guests click to begin the cinematic experience.
- **Wedding Details** — Dedicated sections for Mehfil-e-Nikah and Dawat-e-Valima.
- **Responsive Design** — Optimized for mobile phones, tablets, and desktops.
- **Smooth Animations** — Elegant transitions and scroll effects.
- **Accessibility** — Skip-intro option and reduced-motion support.
- **Optional Background Music** — Guest-controlled audio playback.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_DIRECTORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

> These commands assume a Node.js project using npm. Adjust them to match the existing repository if needed.
